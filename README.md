# Financial-Planning-Analysis-and-Forecasting
FP&amp;A analysis and forecasting project using Excel, covering financial performance, revenue and cost drivers, profitability analysis, and 2026 scenario modeling.

## Overview

Independent FP&A portfolio project analyzing FrieslandCampina's FY2025 financial performance compared with FY2024 and developing illustrative 2026 scenarios.

## Project Objectives

- Analyze revenue and cost performance
- Identify key business and cost drivers
- Assess changes in gross and operating margins
- Build a profitability bridge from FY2024 to FY2025
- Translate financial results into management insights
- Develop Base, Downside, and Upside scenarios for 2026

## Analysis

The workbook includes:

- Executive Summary
- Revenue Analysis
- Costs Analysis
- Profitability Bridge
- 2026 Scenario Analysis
- Management Insights
- Sources & Methodology
- Historical P&L

## Tools

- Microsoft Excel
- Financial modeling
- Scenario analysis
- Variance analysis
- Profitability analysis

## Disclaimer

This is an independent portfolio project based on publicly available financial information. The 2026 scenarios are illustrative assumptions created for analytical purposes and do not represent FrieslandCampina guidance or forecasts.
